# fractal-wasm-benchmark
Performance comparison of JavaScript, WebAssembly and WebAssembly SIMD for fractal generation — master's thesis project

## How to Run
**Requirements:** Python 3 and a modern web browser (Google Chrome recommended).

1. Clone the repository:

```bash
git clone https://github.com/123Mikolaj/fractal-wasm-benchmark.git
```

2. Navigate to the application directory:

```bash
cd fractal-wasm-benchmark/www
```

3. Start a local HTTP server:

```bash
python -m http.server 8080
```

4. Open http://localhost:8080 in your browser.
